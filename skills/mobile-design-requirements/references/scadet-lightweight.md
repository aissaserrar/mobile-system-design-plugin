# Lightweight Daily SCADET Checklist

Use this for most feature work. Keep each section short.

## S – System Requirements
- [ ] 3–5 testable FR with acceptance criteria
- [ ] 2–3 measurable FNR (performance, accessibility, platform, offline…)
- [ ] Explicit Out of Scope

## C – Design Considerations
- [ ] 1–2 key decisions (reuse vs new, server-driven vs local, platform gating…)

## AD – Architecture & API
- [ ] Data-flow sketch
- [ ] Existing pieces that will be reused

## E – Evaluation
- [ ] 1–2 concrete “done” checks

## T – Trade-offs
- [ ] Main trade-off being accepted

**Design System note:** Mention component/token/platform impact inside S or C.
